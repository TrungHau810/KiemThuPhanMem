# KiemThuPhanMem

## Introduction
KiemThuPhanMem is a software testing practice project that focuses on different testing techniques, including:
- Unit Testing
- Automated Web Testing
- API Testing with Postman
The project is designed to improve testing skills and understand how to verify software quality through different levels of testing.

## Features
### Unit Testing - Quadratic Equation Windows Form Application
- Built test cases to verify calculation logic
- Tested valid and invalid inputs
- Automated reading test data from CSV and Excel files

### Automated testing - MWC E-Commerce Website (https://mwc.com.vn/)
- Built automated test cases to verify website functionalities
- Tested login features
- Tested product search and filtering
- Tested add-to-cart and place an order functions
- Verified navigation and UI elements

### API Testing with Postman (API URL: https://dummyjson.com/carts)
- Verified API status codes
- Validated JSON response structure
- Tested CRUD operations
- Tested API data validation and error handling

## Technologies and tools
- C#
- Selenium WebDriver
- NUnit
- Data-Driven Testing
- Postman
